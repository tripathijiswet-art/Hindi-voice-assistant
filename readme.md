# Hindi-voice-assistant
 Hindi Voice Assistant (Offline AI Assistant)

An intelligent, fully offline Hindi Voice Assistant developed using Python.  
This project is specially designed for low-resource devices like Raspberry Pi and works without any internet connection.

It can understand Hindi voice commands, convert them into text, perform actions, and respond using synthetic speech.

---

##  Project Objective

The main objective of this project is to build an offline voice-controlled assistant that:

- Works without internet
- Supports Hindi language
- Runs efficiently on Raspberry Pi
- Helps users perform daily tasks using voice

This project is suitable for embedded systems, IoT applications, and educational purposes.

##  Working Principle

The assistant works in the following steps:

1. Microphone captures user voice
2. Vosk converts speech into text (STT)
3. Python processes the command
4. Program identifies the intent
5. Required action is performed
6. eSpeak-NG converts text to speech (TTS)
7. Audio output is played to user

All processing is done locally.
